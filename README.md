# Prácticas — Curso INAP «La Plataforma de Contratación del Sector Público como herramienta de transparencia»

Repo de trabajo de las prácticas del curso, que se hacen en el entorno de formación `https://preprod-contrataciondelestado.es`. Las ejecuta un agente siguiendo **[AGENTS.md](AGENTS.md)**; el usuario revisa el resultado y lo entrega en el Campus INAP.

- `enunciados/`: enunciados de las prácticas (contrato menor, abierto y abierto simplificado).
- `instrucciones/`: acceso al entorno de prácticas.
- `material-didactico/`: guías de la PLACSP y temario (pendiente de añadir).
- `practicas/`: trabajo, evidencias y textos de entrega. Empieza por `practicas/ESTADO.md`.

Las credenciales van en `credenciales.local.md`, que no se versiona; la plantilla es `credenciales.local.example.md`.
