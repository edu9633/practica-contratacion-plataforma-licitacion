# Material didáctico

Aquí van las **guías de ayuda de la PLACSP** y el **temario del curso**, que aporta el usuario. El agente las consulta antes de cada ejercicio para seguir los pasos exactos en pantalla (ver `AGENTS.md` §2).

Nombres recomendados, para que el agente las encuentre:

| Archivo | Se usa en |
|---|---|
| `guia_acceso-y-roles.*` | Acceso, contextos y usuarios |
| `guia_organos-de-asistencia.*` | Módulo 2: crear la mesa (requisito previo) |
| `guia_contrato-menor.*` | Práctica 00 |
| `guia_configuracion-licitacion.*` | Módulo 3: datos, requisitos, criterios y sobres |
| `guia_publicacion-anuncios.*` | Módulo 4: anuncios, pliegos, DOUE/BOE, preguntas |
| `guia_operador-economico.*` | Registro de empresas, preguntas y presentación de ofertas |
| `guia_sesiones-mesa.*` | Módulo 5: sesiones, actos, informes, actas, comunicaciones |
| `guia_resolucion.*` | Módulo 6: requerimiento, adjudicación, firma, formalización, modificación |
| `guia_abierto-simplificado.*` | Práctica 02 |
| `temario_modulo-N.*` | Teoría de cada módulo |

Se admiten PDF, DOCX o HTML. Si añades una guía con otro nombre, inclúyela en esta tabla.
